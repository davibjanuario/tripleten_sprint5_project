# tripleten_sprint5_project
tripleten_sprint5_project

EDA de veículos nos EUA, com a possibilidade de escolher entre visualizar um histograma ou um gráfico de dispersão.

URL do Render:
https://tripleten-sprint5-project-8xvz.onrender.com

Python, pandas, plotly-express, streamlit

## Como executar localmente
pip install -r requirements.txt
streamlit run app.py
